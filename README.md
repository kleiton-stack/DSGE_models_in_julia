# DSGE MODELS IN JULIA 

In my free time, I’ll be committing new models as I make progress in my Julia studies.

The main goal of this repository is to build a robust database of examples for estimating and simulating DSGE models in Julia, aimed at helping students who can’t afford MATLAB or whose institutions don’t provide an academic license.

Feel free to clone, explore, and contribute to the repository!
